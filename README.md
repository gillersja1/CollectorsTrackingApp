# Collectors Tracking App

An Android application designed to help collectors organize and track their collections.

## Features
- **Modern UI**: Built using Material Design components.
- **Navigation**: Uses the Jetpack Navigation component for seamless transitions between screens.
- **View Binding**: Utilizes View Binding for safer and more efficient UI interactions.
- **Edge-to-Edge**: Supports modern Android edge-to-edge display features.

## Getting Started

### Prerequisites
- Android Studio Meerkat (2024.3.1) or newer.
- Android SDK API Level 24 (Android 7.0) or higher.

### Installation
1. Clone the repository or download the source code.
2. Open the project in Android Studio.
3. Wait for Gradle to sync.

### Running the App
1. Connect an Android device with USB debugging enabled, or start an Android Virtual Device (AVD).
2. Click the **Run** button in the Android Studio toolbar, or press `Shift + F10`.

## Built With
- [Kotlin](https://kotlinlang.org/) - Programming language.
- [Jetpack Navigation](https://developer.android.com/guide/navigation) - For app navigation.
- [Material Components](https://material.io/develop/android) - UI components.
- [View Binding](https://developer.android.com/topic/libraries/view-binding) - For layout interaction.

## Project Structure
- `app/src/main/java/com/example/collectorstrackingapp/`: Contains the Kotlin source code.
- `app/src/main/res/`: Contains layout files, strings, and other resources.
- `app/build.gradle.kts`: App-level build configuration.
